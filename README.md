# FIT14 SUMMER — primera versión PWA

## Qué incluye
- Calendario inicial de 14 días.
- Sesiones breves de técnica, velocidad, fuerza, movilidad y recuperación.
- Calentamiento y estiramientos posteriores.
- Registro flexible de fútbol.
- Recomendación diaria según cómo te sentís.
- Cronómetro guiado por bloques.
- Historial y estadísticas locales.
- Manifest y service worker para instalación PWA.

## Publicación gratuita con GitHub Pages
1. Descomprimí `fit14-summer.zip`.
2. Creá un repositorio público nuevo en GitHub, por ejemplo `fit14-summer`.
3. Subí todos los archivos y carpetas de este proyecto a la raíz del repositorio.
4. En GitHub, entrá a **Settings → Pages**.
5. En **Build and deployment**, elegí **Deploy from a branch**.
6. Elegí la rama `main` y la carpeta `/ (root)`, y guardá.
7. Esperá a que GitHub publique el sitio. La dirección será similar a `https://TU-USUARIO.github.io/fit14-summer/`.

## Instalar en Android
1. Abrí la dirección publicada con Chrome.
2. Abrí el menú de tres puntos.
3. Elegí **Instalar aplicación** o **Añadir a pantalla principal**.
4. Confirmá. La app quedará como icono en el teléfono.

## Importante
- Es una primera versión de prueba, no un APK.
- El historial se guarda localmente en el navegador/dispositivo; no se sincroniza entre dispositivos.
- Para que la PWA y el modo sin conexión funcionen, publicala en HTTPS (GitHub Pages lo proporciona).
- El calendario es un punto de partida flexible. Ajustá o pausá la sesión si aparece dolor, cansancio importante o si ese día ya jugaste fútbol intenso.
- Por tratarse de un adolescente, el plan evita máximos, entrenamiento al fallo y cargas elevadas. Un adulto/entrenador debe supervisar ejercicios de velocidad y fuerza.
